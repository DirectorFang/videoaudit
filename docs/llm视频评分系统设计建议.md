# 基于LLM的视频评分系统设计建议

## 一、引言

在标准化教学场景下，由于 '考试模型统一;操作器械统一;考试流程统一;评分标准固定'这四个原因，使用LLM(大模型)对口腔医学教学视频进行自动评分，并生成评分报告与改进建议，具有可行性

但需要注意的是：

```text
LLM并非真正理解医学操作，而是通过视频画面、音频内容以及评分规则，对考试过程进行规则匹配与结果输出。
```
也即模型的定位是‘检察员’而非‘医学专家’，评分逻辑应该围绕：

```text
发现证据 -> 记录证据 -> 对应评分
```

而非：

```text
观察现象 -> 医学推理 -> 主观判断
```

所以在设计提示词时：

```text 
要围绕‘不要期待模型智能的能力，而要尽量降低模型自由发挥空间'这一原则进行设计。
```

---

# 二、以下是设计llm提示词的一些建议

## 1：评分标准必须先结构化

这是整个系统最重要的前提。

很多考试评分标准原始形式如下：

```text
操作规范
动作熟练
力度适中
探查到位
```

对于考官而言容易理解。

对于LLM而言容易产生歧义。

因此必须先将评分标准转换为：

```text
是否使用牙周探针

是否建立稳定支点

是否完成六个位点探查

是否描述探诊结果
```

即：

```text
专家经验 -> 结构化规则 -> LLM执行
```

如果评分标准本身不够结构化：

即使更换模型也无法获得稳定结果。

---

## 2：评分过程应尽量与考试操作流程保持一致

评分步骤尽量按照考试操作步骤设计。

例如：

```text
第一步 清洁牙面
第二步 酸蚀
第三步 冲洗
第四步 涂布
第五步 固化
第六步 检查
```

而不是：

```text
器械
动作
结果
口述
```

混合评分。

原因：

考试本身是流程型任务。

模型按照操作流程理解视频最容易保持上下文一致。

---

## 3：评分标准拆解到最小采分点

LLM不擅长：

```text
整体印象评分
```

但擅长：

```text
某个动作是否发生
```

因此应设计：

```text
考试评分 -> 行为检测 -> 行为得分 -> 汇总总分
```

而非：

```text
考试评分 -> 直接给总分
```

例如：

```text
器械选择

改良握笔式

建立支点

探针方向

六个位点检查

结果描述
```

应全部独立评分，且为了防止模型自由发挥，对于具体动作最好详细描述，比如 改良握笔式 最好在提示词中明确告诉何为改良握笔式 （其余项同理）。

---

## 4：未观察到不得给分

必须明确：

```text
未观察到 = 不得给分
```

禁止模型出现：

```text
看起来已经完成
```

或：

```text
大概率完成
```

等推测行为。

判定规则：

```text
明确观察到 → 给分

明确观察到错误 → 扣分

无法判断 → 标记无法确认
```

不得出现主观猜测。

---

## 5：视觉证据与音频证据分离

当前主流多模态模型：

主要依赖视频帧进行理解。

对于音频内容：

建议提前进行ASR转写。

然后将转写文本与视频一起输入模型。

### 视觉信息示例

```text
器械选择

握持方式

探针方向

材料涂布范围
```

### 音频信息示例

```text
口述隔湿

口述时间

检查结果描述
```

提示词中必须明确：

```text
哪些评分项依赖视觉

哪些评分项依赖音频

哪些评分项同时依赖二者
```

避免模型跨模态猜测。

---

## 6：评分过程先局部后整体

禁止模型：

```text
先给总分
再找理由
```

正确流程：

```text
评分项1

评分项2

评分项3

……

评分项N

↓

计算总分

↓

生成评价
```

这样可以有效降低整体印象对结果的影响。

---

## 7：固定输出格式

推荐优先输出JSON。

例如：

```json
{
  "score": 8.5,
  "items": [
    {
      "name": "建立支点",
      "score": 0.5,
      "reason": "观察到小指稳定接触模型"
    }
  ]
}
```

如果输出Markdown报告：

也必须固定结构。

例如：

```text
总分

详细评分

扣分说明

改进建议
```

保持一致。

---

## 8：强制说明扣分原因

禁止输出：

```text
操作不规范
```

这类无意义结论。

必须说明：

```text
错误动作

错误位置

对应扣分
```

例如：

```text
探针未与牙体长轴平行

扣0.5分
```

---

## 9：禁止整体印象评分

提示词中必须明确：

```text
不得因为整体表现良好
而默认完成未观察到的步骤
```

考试评分本质是检查表，而非专家印象评价：

---

# 其他

当前直接调用llm评分适用于标准化教学考试场景，但不建议推广到真实临床诊疗场景：

原因：

* 患者个体差异大
* 口腔情况复杂
* 医疗责任问题
* 数据标注成本高

两者技术复杂度差异巨大。

应先在教学场景验证。
